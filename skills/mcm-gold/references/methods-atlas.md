# 方法库、选型决策树与历年题型图谱

---

## 一、选型总则

1. **题面关键词 → 数学问题类型 → 方法族 → 具体算法**，逐级收敛，每级在 `DECISIONS.md` 记理由。
2. **先机理后数据**：能用机理解释的部分优先机理建模，纯数据方法用于机理不明的残差部分。**机理 + 数据混合是高分常见形态。**
3. **复杂度匹配数据量**：小样本上堆深度学习是典型失分点。
4. 每个模型都要能回答：变量是什么、假设是什么、为什么适合本题、**失效条件是什么**。

## 二、五大方法族

### A. 优化与规划
**信号**：最优、最小/最大、配置、调度、路径、策略、方案设计

- **LP / ILP / MILP**：资源配置、选址、排产、指派。工具：PuLP+CBC、Gurobi、Lingo。
- **非线性规划 NLP**：连续设计变量、物理约束。`scipy.optimize`（SLSQP / trust-constr）。
- **多目标优化**：加权法、ε-约束法、**Pareto 前沿**（NSGA-II）。**给出 Pareto 前沿图是高分点。**
- **动态规划 / 最优控制**：分阶段决策、路径依赖、库存、投资。
- **随机规划 / 鲁棒优化 / 机会约束**：题面出现"不确定""波动""风险"时的**加分选择**。
- **元启发式**：GA、模拟退火、PSO、蚁群、禁忌搜索、贪心+局部搜索。**必须报告参数、重复次数、最优/均值/方差，并与精确解或下界对比。**
- **图论与网络流**：最短路、最小生成树、最大流最小割、匹配、网络设计。
- **排队论**：服务系统、机场/医院/窗口调度（M/M/c、M/G/1）。

**陷阱**：目标函数与题意不符；漏约束（尤其隐含的物理/时间/整数约束）；只报最优解不报**求解时间与最优性 gap**；只信建模封装层状态而不读求解器原生日志（PuLP/CBC 到时限有时仍显示 `Optimal`）；启发式跑一次就当结果。

### B. 评价与决策
**信号**：评价、排序、选择、优劣、指标体系、综合

- **主观权重**：AHP（**必须做一致性检验 CR<0.1**）、Delphi。
- **客观权重**：熵权法、CRITIC、主成分/因子分析。
- **组合赋权**：AHP + 熵权（比单一方法更受认可）。
- **排序**：TOPSIS、灰色关联、模糊综合评价、秩和比、DEA。

**加分**：指标体系的构建逻辑（来源→筛选→相关性剔除）；权重的灵敏度分析；**多方法交叉验证排序一致性**。
**陷阱**：指标拍脑袋；未归一化；正负向指标未统一；只用一种方法；不做一致性/稳定性检验。

### C. 预测与时间序列
**信号**：预测、趋势、未来、增长、需求

- **回归族**：多元线性/非线性、岭/Lasso、GLM、分位数回归。**必须做残差诊断与显著性检验。**
- **时序**：ARIMA/SARIMA、指数平滑（Holt-Winters）、STL 分解、状态空间/卡尔曼滤波。
- **灰色预测 GM(1,1)**：小样本短期；**必须做级比检验与后验差检验**，不得长期外推。
- **机器学习**：随机森林、XGBoost/LightGBM、SVR；**小样本慎用神经网络**。
- **组合预测**：加权组合/Stacking，须给权重依据。

**必备**：训练/验证/测试划分（时序按时间切）；多指标评估（RMSE/MAE/MAPE/R²）；**预测区间**（不只是点预测）；外推风险说明。
**陷阱**：数据泄漏；用拟合优度冒充预测能力；无置信区间；小样本长期外推。

### D. 分类、聚类与判别
**信号**：分类、鉴别、识别、分组、异常

- **有监督**：Logistic、LDA/QDA、决策树、随机森林、SVM、KNN、集成。评估用**混淆矩阵 + 精确率/召回率/F1/AUC**；不平衡时报告 PR 曲线。
- **无监督**：K-means（定 k：肘部/轮廓系数/GAP）、层次聚类、DBSCAN、GMM。**必须验证聚类有效性并给出簇的可解释含义。**
- **降维**：PCA、t-SNE/UMAP（**仅可视化，不做结论**）、特征选择。
- **异常检测**：3σ/箱线图、孤立森林、One-Class SVM、马氏距离。

**加分**：特征工程有机理依据；可解释性（特征重要性、SHAP）；小样本下的交叉验证与稳定性。
**陷阱**：只报准确率（不平衡数据下无意义）；聚类结果无业务解释；用 t-SNE 图当证据。

### E. 机理建模与仿真
**信号**：过程、演化、传播、运动、受力、反应、系统

- **微分方程**：ODE（动力学/SIR 族/种群/反应）、PDE（扩散/热传导/波动）、时滞与随机微分方程。数值解：Runge-Kutta、有限差分/有限元。
- **参数辨识与反演**：最小二乘、极大似然、贝叶斯反演（MCMC）、正则化。
- **仿真**：蒙特卡洛、离散事件、元胞自动机、多智能体、系统动力学。**必须报告重复次数与置信区间。**
- **几何/物理计算**：坐标系设定、刚体运动学、投影与遮挡、碰撞检测（近年 A 题高频）。

**加分**：机理模型与实测数据的定量吻合度；无量纲化与特征尺度分析；守恒律校验。
**陷阱**：坐标系/单位混乱；步长不做收敛性验证；仿真跑一次就下结论；**把仿真当作对模型的"验证"**（仿真验证的是实现，不是模型正确性）。

## 三、交叉组合（高分常见形态）

| 组合 | 场景 | 要点 |
|---|---|---|
| 机理 + 数据同化 | 机理不完备但有观测 | 机理给骨架，残差用统计/ML 修正；卡尔曼滤波/贝叶斯更新 |
| 优化 + 仿真 | 目标函数无解析式 | 仿真评估 + 元启发式搜索 |
| 预测 + 优化 | 先预测需求再决策 | **必须把预测不确定性传入优化**（随机规划/鲁棒优化），否则是脱节的两段式 |
| 聚类 + 分组建模 | 群体异质 | 先分层再逐层建模，通常显著优于全局单模型 |
| 多目标 + 决策评价 | 方案取舍 | Pareto 前沿 + TOPSIS/AHP 选推荐方案 |
| 贝叶斯层次模型 | 多来源/小样本 | 借力共享信息，天然给出不确定性 |

### 规律提炼

- **A 题**：物理/工程机理为主（几何 + 微分方程 + 优化），计算密集、结果客观，**对量纲与几何严谨性要求最高**。
- **B 题**：跨度最大，可能是工程反演、几何定位、化工数据建模，常需**机理 + 数据**结合。
- **C 题**：经管/统计/数据分析，门槛低、**竞争最激烈**，胜负手在**数据处理细致度 + 决策模型闭环 + 差异化视角**。
- **D/E 题**（高职高专组）：优化与分类/预测为主，**规范性与完整度**权重更高。
- **跨年高频技能**：几何建模、微分方程数值解、MILP、蒙特卡洛、回归与检验、聚类判别、多目标优化、灵敏度分析。
