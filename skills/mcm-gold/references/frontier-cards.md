# 前沿方法卡片库（2023–2026）

> 按需加载。**进来前先读 `methods-atlas.md` 五、的选卡索引**，锁定 1–2 张候选再读本文件对应行。

**如果只用一张卡：用 A1 全局灵敏度分析（SALib）**——4h 落地、每篇论文本来就必须写灵敏度章节、数学教授零反感，是唯一「不用也得用、用了必加分」的一张。

**排序**：按竞赛性价比 = 落地成本低 × 评委认可度高。**甲级**（≤5h 且评委零风险，默认从这里挑）→ **乙级**（≤6.5h 或有前置条件）→ **丙级**（≥7h、适用面窄或答辩风险高，仅当题目正中靶心时用）。`h` 为「基线代码已跑通 + 3 人分工」下的净耗时，含装环境与对照实验；所有版本号/API 名均经实测或官方文档核对，抄代码前仍 MUST `print(dir(库))` 核对本机版本。

## 0. 使用纪律（先于任何卡片生效，违反即整节禁用）

1. **基线优先**：T4 Gate 未过（第 1 问尚无基线数值与图）时，**禁止**引入本节任何方法。没有基线的前沿方法 = 赌博。
2. **对照强制**：MUST 交出同数据、同划分、同预算的定量对照表（前沿法 vs 被它替代的经典法）。**无对照表的前沿方法一律按「炫技但没解决问题」判定，减分大于加分。**
3. **可解释强制**：MUST 能做参数扫描/灵敏度，且能向数学教授口头讲清原理、假设与失效条件。讲不清 → 不用。
4. **配额**：一篇论文前沿卡 ≤2 张；同族（共形族 / DRO 族 / 贝叶斯优化族 / 因果族）**至多 1 张**。堆三张以上必被判炫技。
5. **时间硬闸**：最后 8h 禁止引入新卡（SKILL.md §3.4）；任一卡实际耗时超 8h 立即弃用、回退经典法并记 D-log。
6. **环境前置**：T0 赛前 MUST 在全部参赛机器各装通一次并跑出 hello-world（Windows 编译依赖是第一杀手）。
7. **诚实条款**：输给对照组要如实写负结论（负结论也是结论）；**禁止**隐去不利对比或引用未真正跑出的指标。
8. `research.frontier_methods: forbid` 时整节失效。

**选卡索引以 [`methods-atlas.md` 第五节](methods-atlas.md) 为唯一权威，本文件不再复制**——按题型收敛到 1–2 张候选后，回本文件读对应行的库版本、API、实测翻车条件。
