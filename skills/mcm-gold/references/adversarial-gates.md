# 对抗式质量门禁、反幻觉铁律与终检清单

---

## 一、门禁机制

- 每个阶段结束前，切换到**「怀疑论评委」角色**，尝试**推翻**本阶段结论。
- 只有经受住攻击的结论标记 `CONFIRMED` 并写入 `RESULTS.md`；未通过标记 `SUSPECT` 并列入 `RISKS.md`。
- **审查报告须附否决清单**（哪些疑点被检查过、为何判定不成立），防止下一轮重复上报同样疑点。
- `paranoid` 档：跑两轮独立红队，第二轮不看第一轮结论。
- `paper-ready` 不是“文字看起来完整”：必须满足 `references/evidence-contract.md` 的 claim 链，并由适用的 H-001~H-004 人类签署；演练代理最高标 `rehearsal_confirmed`。
- Gate 的每个 PASS 写入 `REVIEW_PASS_ITEMS.csv`，至少包含文件位置、实际观测、期望/容差、命令或 R-id、检查者和时间。只有“已检查”字样视为未通过。

## 二、红队攻击清单（gold 档全跑）

### 模型层
1. 目标与物理交付是否逐项对应题面动词？证据 Gate 若不支持字面要求的强结论，是否同时保留 `operational_claim` 与醒目标注假设/失败指标/禁止用途的 `literal_artifact`，而非漏答或降 Gate？
2. 是否漏掉题面明确给出的约束（时间窗、整数性、容量、物理边界）？
3. 假设与模型是否矛盾（假设独立却用了相关结构，或反之）？
4. 极端参数下是否退化为荒谬结果（负数量、概率>1、超物理极限）？
5. 换一个合理的建模视角，结论会翻转吗？若会，为何选现在这个？

### 数据层
6. 有没有**数据泄漏**（用未来信息、用测试集调参、目标编码泄漏）？
7. 缺失/异常处理是否改变了结论？做一次"不处理 vs 处理"的对比。
8. **单位与量纲**是否全程一致？逐公式核。
9. 样本量是否支撑所用模型复杂度？
10. 数据口径是否与题面定义一致（同名不同义）？模型候选键在数据中未出现时，是结构性 0、未知缺失还是不适用？是否因 `inner join`/只遍历已出现键而静默漏掉约束？

### 计算层
11. 结果对**随机种子**敏感吗？跑 ≥5 个种子看方差。
12. 数值解对**步长/网格/迭代次数**收敛吗？解析场应直接在积分/求积点计算，绘图或报告网格不得反向进入求解器；做网格不变性与收敛回归。
13. 优化结果是全局还是局部？多起点/对比下界/报告 gap。**必须以求解器原生日志的终止原因和上下界为准**；封装层显示 `Optimal` 但原生日志写 `Stopped on time limit` 时，一律判为限时可行解。
14. 有没有**独立实现的交叉验算**（换方法或换工具算同一量）？必须列明数据解析、插值/特征、核心方程/几何、目标/约束、求解器和评价器中哪些独立、哪些共享；只换一个轴只能称部分独立。
15. 计算能在合理时间内复现吗？清环境重跑。
16. 候选池/场景筛选的覆盖与多样性是否有证据？“多种子不翻转”是否可能只是候选集过窄，而非原问题真正稳健？

优化结果的 `RESULTS` 证据至少包含：`termination`、可行目标值、best bound、相对 gap、time limit/实耗时、变量数、约束数、最大整数偏差/约束残差和原生日志路径。残差需给绝对量及相对业务尺度；若因求解器解文件精度造成连续量微小越界，固定离散决策后重求连续量或执行可审计的边界修复，并记录目标变化。任一项缺失，不得在摘要中使用“最优”。

### 结论层
17. 结论是否**超出数据与模型能支撑的范围**？操作结论与探索性字面工件是否在摘要、正文、图表中保持分层，避免过度外推、因果/相关或稳定/探索混写？
18. 论文中每个数字是否都能在 `RESULTS.md` 找到运行记录？
19. 图表与正文、摘要中的数字是否完全一致？
20. 灵敏度是否只做了单因素？多因素联合扰动做了吗？
21. 关键假设若被否，论文有没有给出后备说明？

### 表达与合规层
22. 摘要能否独立传达具体结论？
23. 有没有模板腔/网上常见段落（相似度风险）？
24. 是否有身份信息泄漏（PDF 元数据、代码路径中的用户名、图片 EXIF、Git 配置）？
25. 页数/文件大小/页码/文件命名是否达标？
26. 参考文献之前是否有与实际使用一致的 2026 版 AI 声明；使用 AI 时是否有 `AI 工具使用详情.pdf`、逐项人工核验和队员主导核心建模/分析的证据？
27. 题意、路线、关键事实、结果解释与最终提交是否分别关联适用 H-001~H-005？AI 是否把代理判断写成人的确认？
28. 冻结后的数值/结论是否用新 R/C/F-id 替代并记录 `SUPERSEDED`？主状态目录是否拒绝复用 R-id，避免重跑产生的新 `PENDING` 遮蔽已确认记录？
29. 每个准备进入论文的 claim/figure 是否能沿证据链回到真实运行或权威来源，并有具体 PASS evidence？

### 前沿方法层（仅当引入了 `frontier-cards.md` 的卡片）
30. 每张前沿卡是否有**同数据、同划分、同预算**的经典法对照表，且在 `RESULTS.md` 有运行记录 ID？无对照表 = 炫技，减分。
31. 是否超配额（全文 ≤ `frontier_cards_quota`、同族 ≤1 张）？
32. 卡片 failure_modes 标注的必检项是否逐条落实（如 A2 的三分数据划分图、A5 的 resample 纳入率、A8 的样本 i.i.d. 来源）？

## 三、反幻觉铁律（**违反即视为造假**）

1. **数值可追溯**：模型输出/结论数值关联 `RESULTS.md` 的 R-id（脚本、命令、种子、时间戳、输入 SHA-256）；外部事实/参数关联 `SOURCES.md` 的 S-id；题面给定量标明页码或附件字段。
2. **禁止"预期结果"**：不得写下未真正计算出的数值、图表或表格。来不及算就**如实缩减结论范围**，不得编造。
3. **禁止幻觉文献**：参考文献必须真实可访问（URL/DOI 经过验证）。**宁可少引，不可编引。**
4. **代码未跑通不得引用其输出**；图必须由脚本生成且可重跑。
5. **估计值必须显式标注**："估计值/文献值（来源[x]），并已做灵敏度分析"。
6. **不确定就写不确定**：给区间、给条件、给失效边界，而不是给一个自信的错数。
7. 汇报时**区分「逻辑自洽」与「实测验证」**：前者不得表述为"已验证"。

## 六、终检清单（T8，逐条勾选，**禁止跳过**）

### 内容
- [ ] 每个小问都有题面要求形态的物理工件；证据不足项同时给操作结论与醒目标注的探索工件，无遗漏、无降 Gate、无"留待后续"
- [ ] 摘要含数值结论与创新点，一页内，无模板腔
- [ ] 假设逐条被使用/被检验，无孤立假设
- [ ] 模型链清晰：基线 → 主模型 → 改进，各自结果可对比
- [ ] 六类检验均有 R-id 证据；不适用项有 D-log 的 `N/A + 原因 + 替代检查`
- [ ] 创新点 ≥ `innovation_quota` 且在摘要点名
- [ ] `CLAIM_LEDGER.csv` 中进入摘要/正文的条目都有 R/S/F-id，状态达到正式 `confirmed` 或演练 `rehearsal_confirmed`
- [ ] H-001 至 H-004 的适用项已由人确认；演练若为 `PROXY_REHEARSAL`，交付状态明确写“非正式提交”

### 一致性
- [ ] 摘要数字 = 正文数字 = 图表数字 = `RESULTS.md`
- [ ] 符号全文统一，符号表完整
- [ ] 公式编号连续，正文引用正确
- [ ] 参考文献编号与正文标注一一对应，条目真实可访问
- [ ] 参考文献之前存在 2026 版“AI 工具使用声明”；使用 AI 时支撑包含文件名完全一致的 `AI 工具使用详情.pdf`
- [ ] AI 参与内容有逐项人工审查与核实证据，核心建模与分析有参赛队主导记录；未沿用 2025 版正文标注/AI 参考文献旧模板作为强制项

### 机器可检
- [ ] 正文页数 ≤30 且无目录
- [ ] 论文 ≤20MB 且未压缩；支撑材料 ≤20MB
- [ ] 页码自摘要页起连续、位置正确
- [ ] PDF 可正常打开、字体嵌入、图片清晰
- [ ] **匿名扫描**：全文 + PDF 元数据 + 代码注释 + 文件路径 + 图片 EXIF 无学校/姓名/赛区
- [ ] 支撑材料解压后 `run_all` 可跑通
- [ ] 官方结果模板（若有）已从提交副本回读，业务键、非零单元和总量与内部计划逐项一致；合并单元格、公式、header/footer 等 T3 登记结构未被编辑库静默删除

### 合规
- [ ] `rules-2026.md` 第五节 checklist 全绿（含 AI、匿名与相似度自查）
- [ ] H-005 已由人确认 AI 披露、最终文件、剩余风险和提交授权；AI 未代签

### 提交
- [ ] 截止前 **≥2 小时**完成提交
- [ ] 提交后重新下载核验文件完整可打开
- [ ] 归档过程档案

## 七、机器终检参考命令

```bash
paper=deliverables/submission/paper.pdf; support=deliverables/submission/support.zip
pdfinfo "$paper"; wc -c "$paper" "$support"                    # 各自必须 ≤20971520 bytes
pdffonts "$paper"                                                # emb 列逐行必须为 yes
pdftotext -layout "$paper" - | awk 'BEGIN{RS="\f"} /附录/{print "附录起始PDF页=" NR; exit}' # 应 ≤32
for p in $(seq 1 "$(pdfinfo "$paper" | awk '/^Pages:/{print $2}')"); do printf '%s: ' "$p"; pdftotext -f "$p" -l "$p" -layout "$paper" - | tail -n 4 | tr '\n' ' '; echo; done # 核页码连续
unzip -t "$support"                                               # 压缩包完整性
grep -rInI -iE "学校|大学|学院|姓名|指导教师|队号|/Users/|/home/" deliverables/staging/support/
exiftool "$paper" | grep -iE "author|creator|producer|title"
exiftool -r deliverables/staging/support/figures/ | grep -iE "author|comment|software"
```
必须读取每条输出：命中身份词先人工判断是否为引用机构；正文 30 页以摘要为 PDF 第 1 页、附录最迟从第 32 页开始计算。无 `exiftool/pdffonts` 时记录工具缺失并改用 `pdfinfo` 加导出设置清空属性，不得直接勾选通过。
