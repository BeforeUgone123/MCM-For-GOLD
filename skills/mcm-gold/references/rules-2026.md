## 二、论文格式规范（2026 修订稿）逐条

### 纸质版
1. 白色 A4（单/双面均可），**上下左右页边距各 ≥2.5 cm**，**左侧装订**。
2. 顺序固定：**承诺书 → 编号专用页 → 摘要专用页（从此页起编页码）→ 正文 → 附录**。
3. 摘要（含标题与关键词，**无需英文**）**原则上不超过一页**。
4. 页码：**页脚中部，阿拉伯数字从 1 连续编号**。
5. 正文**不要目录**、**不超过 30 页**。
6. 附录**必须打印并与正文装订在一起**，须含：**支撑材料文件列表** + **建模用到的全部完整、可运行源程序代码**（含 EXCEL、SPSS 等交互命令）。无程序须写明"本论文没有用到程序"。
7. **摘要页、正文、附录任何位置不得出现参赛者身份、学校、赛区信息。**
8. 引用他人或公开资料（含网络资料）MUST 按科技论文规范列参考文献并在正文标注。
9. 字号、字体、行距、颜色**不做统一要求**。

### 电子版
10. 提交两个文件：**参赛论文** + **支撑材料**。
11. 论文电子版内容与格式（含附录）须与纸质版**完全一致**；PDF 或 Word（**建议 PDF**）；**≤20 MB**；**不要压缩**。
12. **电子版论文第一页必须是摘要专用页**；**承诺书与编号专用页不放入电子版**。
13. 支撑材料：至少含所有可运行源程序、自主查阅使用的数据资料（**赛题提供的原始数据除外**）、较大篇幅中间结果图表；打包 **RAR/ZIP，≤20 MB**；文件列表须置于论文附录；确无支撑材料须在附录注明。
14. 支撑材料同样**不得含身份/学校/赛区信息**。
15. **不符合规范的论文视为违反竞赛规则，可能被取消评奖资格。**

## 三、AI 工具使用规定（2025 年试行，2025-09-01 起试行）

截至 **2026-08-02**，官网“章程及规则”仍只列出 2025 年试行版，未发现 2026 版；开赛前 24h 再核验。

1. 适用范围：**大语言模型、生成式 AI、代码辅助工具、智能数学软件**等。
2. **未使用 AI**：须在**参考文献之后**明确声明"**本参赛队未使用任何AI工具**"。
3. 使用 AI：遵循**公开透明**原则；**核心建模与分析必须由参赛队独立完成**。
   > **执行性解释（非官方原句）**：「事后验证」不等于「独立完成」。模型形式选择、关键假设设定、结论判断须由队员先行给出并在 D-log 留下时间戳和依据；AI 产物只能作为候选项与实现工具。
4. **正文标注**：AI 生成的内容须在相应位置标注。
5. **参考文献著录**：`[编号] 工具名称，版本/型号，开发机构/公司，使用日期`
   例：`[1] DeepSeek, DeepSeek-R1-0528, 深度求索（DeepSeek）, 2025-09-05`
6. **支撑材料**须含 PDF 文件《**AI工具使用详情**》：工具名称与版本、具体使用目的与环节、**关键交互记录**、**采纳及修改情况**。
7. 不符合要求者视为违规，**取消评奖资格**。

> **对执行者的直接含义**：从第一分钟起**同步维护 `AI_USAGE.md`**，而不是赛末补写——补写必然遗漏关键交互记录，属高危违规。
> **提醒义务**：当用户以 AI 完成大量工作时，MUST 主动提示申报义务与"核心自主"要求，并在每阶段末尾追加当轮 AI 使用记录。**这不是可选项。**

## 四、评阅机制（决定了论文该怎么写）

- **两级评阅**：赛区评阅 → 全国评阅。
- 赛区评阅：论文**随机编号**、**回避制度**、**每篇至少 3 位评委独立评阅**、评阅时间**不少于 2 天**；组长先组织全体评委对**赛题、评阅要点、可能的解题思路**充分讨论，形成**可操作的评阅细则**；分歧大时复议。
- **相似度红线**：两个相似度中**任一 ≥25%** 的论文原则上不能报送全国评阅。
- 报送全国数量先按报名队数**分段累进**计算基数：前 200 队 12%、201–500 队 10%、501–800 队 8%、801 队起 5%，再按当年 A/B 控制参数折算；不得把某档比例乘以全部报名队数。
- **同一学校同一题**报送全国 **≤4 篇**，其中申报一等奖 **≤2 篇**；申报一等奖数量 **≤报送总量 40%**；赛区申报全国二等奖的论文**原则上不推荐**为全国一等奖。
- 每赛区每题可额外报送**最多 1 篇**"有突出创新点但整体未达全国奖水平"的创新论文。

### 战术推论（极其重要）

1. 评委在**共识细则**下打分 → 论文必须**主动对齐题目的"标准解法骨架"**，再在其上叠加创新；完全另起炉灶的奇解风险极高。
2. 至少 3 位评委独立评阅 + 复议 → **一眼可辨识的结构与图表**比藏在文字里的巧思更值钱。
3. 相似度红线 → **禁止套用网上模板段落**，尤其"问题重述""模型评价"这类高重复段落必须自己写。
4. 报送名额受**同校同题**限制 → 差异化（视角/数据/方法组合）本身就有分。

## 五、合规 checklist

**纪律**
- [ ] 全程未与队外任何人交流赛题，且未在交流平台浏览、发布或讨论任何与本届赛题相关的内容
- [ ] 竞赛期间未接受指导教师任何形式指导
- [ ] 未在任何平台发布/分享题目、思路、代码
- [ ] 引用规范标注、无大篇幅照抄；**四类高重复段落（问题重述、模型假设套话、模型评价、算法通用描述）逐段确认为自写**——联网时每段抽 1 条 ≥15 字连续片段检索，命中他人原文即整段重写。**无查重工具时禁止直接勾选"相似度<25%"**，按本条判定

**格式（对照第二节逐条）**
- [ ] 纸质版：页边距/装订/五部分顺序/摘要≤1页/页码/正文无目录且≤30页/附录含代码与文件列表
- [ ] 摘要页、正文、附录**无任何身份信息**
- [ ] 电子版：与纸质版完全一致 / PDF / ≤20MB / 未压缩 / **首页为摘要页** / 不含承诺书与编号页
- [ ] 支撑材料：RAR或ZIP / ≤20MB / 含全部可运行源程序与自主查阅使用的数据 / 文件列表已写入附录 / **无身份信息**（含文件属性、代码路径、注释、Git 配置）

**AI 合规**
- [ ] 使用了 AI：正文已标注 + 参考文献已著录 + 《AI工具使用详情》PDF 已打包
- [ ] 未使用 AI：参考文献后已声明"本参赛队未使用任何AI工具"

### 学术诚信红线

禁止抄袭（文字、公式、图表、代码，网络资料同样受限）｜禁止伪造或篡改数据与结果｜禁止使用他人未公开的解答。

```yaml
  name: "XX杯 2026"

  paper: {max_pages: 20, include_appendix_in_pages: true, file_size_mb: 15, anonymity: strict}
  abstract: {max_pages: 1, language: zh}
  submission: {deadline: "...", platform: "...", naming: "{队号}_论文.pdf"}
  ai_policy: {allowed: true, declaration_required: true, detail_file: "AI使用说明.pdf"}
  judging_principles: ["假设合理性", "创新性", "正确性", "表达清晰"]
  extra_deliverables: ["一页决策建议书"]
```
