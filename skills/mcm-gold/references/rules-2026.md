### 参赛规则要点

- 指导教师**仅负责赛前辅导与组织**，竞赛期间**不得以任何方式指导**（含向学生解释赛题或提供选题、解题建议，提供参考资料，修改论文或提供修改建议等），违者两年内不受理其报名。
- 参赛队 MUST 独立完成。**严禁与队外任何人**（含指导教师）以任何方式交流、讨论任何与赛题有关的问题；**无论主动参与讨论还是被动接收讨论信息，均视为严重违反竞赛纪律**。

- 引用须规范标注，**不得大篇幅照抄**，否则按学术不端处理。
- **允许使用 AI 工具作为辅助**，但参赛队对作品的原创性、真实性、准确性**负全部责任**，且须遵守《人工智能工具使用规定》。
- 违反承诺或不符合章程/格式规范的论文将被**无条件取消评奖资格**；严重、典型违纪还可能被公开通报并由学校处理。
- 本规则未详述的内容，另见《竞赛章程》《论文格式规范》《人工智能工具使用规定》和**竞赛网站发布的通知**。

## 二、论文格式规范（2026 修订稿）逐条

### 纸质版
1. 白色 A4（单/双面均可），**上下左右页边距各 ≥2.5 cm**，**左侧装订**。
2. 顺序固定：**承诺书 → 编号专用页 → 摘要专用页（从此页起编页码）→ 正文 → 附录**。
3. 摘要（含标题与关键词，**无需英文**）**原则上不超过一页**。
4. 页码：**页脚中部，阿拉伯数字从 1 连续编号**。
5. 正文**不要目录**、**不超过 30 页**；正文之后是附录，**附录页数不限**（不必为了页数删代码）。
6. 附录**必须打印并与正文装订在一起**，须含：**支撑材料文件列表** + **建模用到的全部完整、可运行源程序代码**（含 EXCEL、SPSS 等交互命令）。无程序须写明"本论文没有用到程序"。
   → **红线（第五条原文后半句）**：**缺少必要的源程序、程序不能运行，或运行结果与论文不符，都可能被取消评奖资格。** 这是"附录代码必须真能跑通、且跑出来的数就是论文里的数"的官方依据，不是内部质量标准。
7. **摘要页、正文、附录任何位置不得出现参赛者身份、学校、赛区信息。**
8. 引用他人或公开资料（含网络资料）MUST 按科技论文规范列参考文献并在正文标注。
9. 字号、字体、行距、颜色**不做统一要求**。→ **但第八条同时规定：在不违反本规范的前提下，各赛区可以对论文做相应的要求。** T0 MUST 另查本赛区通知，赛区附加要求写入 CONFIG 与终检清单；只核全国级规则不算查完。

### 电子版
10. 提交两个文件：**参赛论文** + **支撑材料**（按《报名和参赛须知》要求提交）。
11. 论文电子版内容与格式（含附录）须与纸质版**完全一致**；**必须是一个单独的文件**；PDF 或 Word（**建议 PDF**）；**≤20 MB**；**不要压缩**。
12. **电子版论文第一页必须是摘要专用页**；**承诺书与编号专用页不放入电子版**。
13. 支撑材料：至少含所有可运行源程序、自主查阅使用的数据资料（**赛题提供的原始数据除外**）、较大篇幅中间结果图表；打包 **RAR/ZIP，≤20 MB**；文件列表须置于论文附录；确无支撑材料须在附录注明"本论文没有支撑材料"。
    → **红线（第十一条原文后半句）**：**支撑材料文件与论文内容不相符，该论文可能被取消评奖资格。** 支撑包与论文必须同版本冻结，禁止交旧副本。
14. 支撑材料同样**不得含身份/学校/赛区信息**；承诺书与编号专用页也不要放进支撑材料。
15. **不符合规范的论文视为违反竞赛规则，可能被取消评奖资格。**

> **三条取消资格红线小结**（T8 必须逐条留证，见第五节 checklist）：① 缺源程序 / 程序跑不通 / 运行结果与论文不符；② 支撑材料与论文内容不相符；③ 不符合格式规范。前两条正是 `run_all.py` 清环境复现与打包一致性检查存在的理由。

## 三、AI 工具使用规定（2026 年试行，2026-09-01 起试行）

原文：`../../../sources/official/2026/cumcm-ai-tool-policy-2026.pdf`，第 1 页，第 1–7 条。

1. 适用范围包括但不限于**大语言模型、生成式 AI、代码辅助工具和 AI 智能体**。
2. 不要求必须使用 AI。允许竞赛期间使用，但必须公开透明，确保作品的**核心建模与分析由参赛队主导**，并对 AI 参与完成的内容**逐项人工审查与核实**；参赛队对原创性、真实性和准确性负全部责任。
3. 必须在**论文参考文献之前**设置“**AI 工具使用声明**”，二选一：
   - 未使用：`本参赛队在竞赛过程中未使用任何 AI 工具。`
   - 已使用：`本参赛队在竞赛过程中使用了 AI 工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。`
4. 已使用 AI 时，支撑材料必须包含 PDF：`AI 工具使用详情.pdf`，包括：
   - AI 工具名称、版本或型号；
   - 具体使用目的和环节；
   - 主要提示方式与使用过程说明，可附典型交互示例；
   - 对 AI 输出的采纳、人工修改和核验的主要情况；语言润色可不写本小项，但仍受第 2 条逐项人工审查与核实义务约束。
5. 不符合规定将按情节处理；**故意隐瞒、虚假声明，或把未经必要人工审查与核实的 AI 生成内容直接作为核心建模与分析成果提交，取消评奖资格**。
6. 2026-09-01 起试行；此前规定与本规定不一致时，以 2026 版为准。

2026 版不再列出 2025 版的“正文逐处标注 AI 内容”和“把 AI 工具作为参考文献著录”要求。不得把旧模板继续当作 2026 强制项；最终仍以开赛前官方最新原文为准。

> **执行含义**：从第一次使用起同步维护 `AI_USAGE.md`；每条核心建模/分析内容关联队员主导记录、AI 用途、实际核验和采用状态。赛末补写容易遗漏，不得用“人工看过”替代逐项核验。

## 四、评阅机制（决定了论文该怎么写）

> **证据等级 `URL_ONLY(2025)`**：本节全部数字来自《赛区评阅工作规范（**2025** 修订稿）》，仓库内**无快照、无哈希**，且 2026 版可能已修订。战术推论（结构对齐、图表可辨识、自写高重复段落）与版本无关可继续沿用；**相似度阈值、报送比例、名额上限这三类数字在引用进论文或决策前 MUST 重新核验官网当年版本**。

- **两级评阅**：赛区评阅 → 全国评阅。
- 赛区评阅：论文**随机编号**、**回避制度**、**每篇至少 3 位评委独立评阅**、评阅时间**不少于 2 天**；组长先组织全体评委对**赛题、评阅要点、可能的解题思路**充分讨论，形成**可操作的评阅细则**；分歧大时复议。
- **相似度红线**：两个相似度中**任一 ≥25%** 的论文原则上不能报送全国评阅。
- 报送全国数量先按报名队数**分段累进**计算基数：前 200 队 12%、201–500 队 10%、501–800 队 8%、801 队起 5%，再按当年 A/B 控制参数折算；不得把某档比例乘以全部报名队数。
- **同一学校同一题**报送全国 **≤4 篇**，其中申报一等奖 **≤2 篇**；申报一等奖数量 **≤报送总量 40%**；赛区申报全国二等奖的论文**原则上不推荐**为全国一等奖。
- 每赛区每题可额外报送**最多 1 篇**"有突出创新点但整体未达全国奖水平"的创新论文。

### 战术推论（极其重要）

1. 评委在**共识细则**下打分 → 论文必须**主动对齐题目的"标准解法骨架"**，再在其上叠加创新；完全另起炉灶的奇解风险极高。
2. 至少 3 位评委独立评阅 + 复议 → **一眼可辨识的结构与图表**比藏在文字里的巧思更值钱。
3. 相似度红线 → **禁止套用网上模板段落**，尤其"问题重述""模型评价"这类高重复段落必须自己写。
4. 报送名额受**同校同题**限制 → 差异化（视角/数据/方法组合）本身就有分。

## 五、合规 checklist

### 检索纪律（联网时逐条生效，直接来自参赛规则第 5 条）

官方把**「浏览」本身**列为严重违反竞赛纪律，且点名了平台。AI 辅助检索最容易踩的就是这一条——中文检索"某模型 Python 实现"极易落到 CSDN，"某算法代码"极易落到 GitHub。

- **禁入域名（官方点名，"包括但不限于"）**：`tieba.baidu.com`、`zhihu.com`、`xiaohongshu.com`、`csdn.net`、`github.com`、`gitee.com`（同类）、QQ/微信群、各类直播与题解社区。规则原文为开放列举，**同性质的题解/答疑/代码分享站一律按同一标准处理**。
- **允许检索**：官方站点与通知、国家/行业标准、政府与机构统计数据、同行评议论文与预印本、库的官方文档与 API 参考、教科书与讲义。
- **判定口径**：禁的是**与本届赛题相关的内容**（题目、思路、题解、他队代码、赛题讨论），不是通用方法学。在 GitHub 上查某个库的 issue 与在 GitHub 上搜"2026 A 题"性质完全不同——但**竞赛期间对点名平台一律不进**，需要库文档就用官方文档站或本地 `pip show`/`help()`/`print(dir(库))`。
- **执行**：live 模式只直接访问已判定安全的官方/标准/论文/数据 URL，或使用能在请求前强制域名白名单的检索接口；不能强制白名单时不做开放网页检索。检索前把白名单、禁入域名和直接 URL 写进 `MCM-Result/Reference-Papers/SEARCH_LOG.md`；**误开禁入页面时立即关闭、记入该日志与 `MCM-Result/Intermediate-Outputs/RISKS.md`，该页内容不得进入任何产物**，不得因为"已经看到了"就顺手采用。
- 无联网能力时置 `research.online=false`，**禁止编造来源去过 T2 Gate**。

**纪律**
- [ ] 全程未与队外任何人（含指导教师）交流赛题；**无论主动讨论还是被动接收信息**均未发生
- [ ] 竞赛期间未接受指导教师任何形式指导（含解释赛题、选题/解题建议、提供资料、修改论文或提修改建议）
- [ ] 未在任何平台发布/分享题目、思路、代码
- [ ] **检索纪律全程执行**：`SEARCH_LOG.md` 无禁入域名采用记录；误命中已登记并弃用
- [ ] 引用规范标注、无大篇幅照抄；**四类高重复段落（问题重述、模型假设套话、模型评价、算法通用描述）逐段由队伍自行重写并人工确认**。**live 模式禁止通用网页查重**；只允许赛事认可的查重系统或赛前已固化的本地语料检查。无合规查重工具时禁止勾选“相似度<25%”，只能记录“未实测，已完成自写与人工复核”

**格式（对照第二节逐条）**
- [ ] 纸质版：页边距/装订/五部分顺序/摘要≤1页/页码/正文无目录且≤30页/附录含代码与文件列表（**附录页数不限**，不必为页数删代码）
- [ ] 摘要页、正文、附录**无任何身份信息**
- [ ] 电子版：与纸质版完全一致 / **单独一个文件** / PDF / ≤20MB / 未压缩 / **首页为摘要页** / 不含承诺书与编号页
- [ ] 支撑材料：RAR或ZIP / ≤20MB / 含全部可运行源程序与自主查阅使用的数据 / 文件列表已写入附录 / **无身份信息**（含文件属性、代码路径、注释、Git 配置）
- [ ] **本赛区附加要求已查证并逐条满足**（格式规范第八条允许赛区另提要求）；无附加要求也须写明查证时间与来源，不得默认"只有全国级规则"

**三条取消资格红线（逐条留实测证据，不接受"应该没问题"）**
- [ ] **源程序完整且真能跑通**：附录代码 = 支撑包代码，清环境 `run_all` 实跑通过（留日志）
- [ ] **运行结果与论文一致**：清环境重跑的关键数值逐项等于论文/图表/`RESULTS.md` 的数值（留比对记录）
- [ ] **支撑材料与论文内容相符**：支撑包与提交论文同版本冻结、哈希已记录，未混入旧副本

**AI 合规**
- [ ] 参考文献**之前**已设置“AI 工具使用声明”，并使用 2026 版对应原文
- [ ] 使用了 AI：`AI 工具使用详情.pdf` 已打包，名称/版本或型号、目的环节、提示与过程、采纳/修改/核验记录齐全
- [ ] 核心建模与分析有参赛队主导证据，AI 参与内容已逐项人工审查和核实
- [ ] 未使用 AI：声明为“本参赛队在竞赛过程中未使用任何 AI 工具。”，且支撑材料/过程记录没有相反证据

### 学术诚信红线

禁止抄袭（文字、公式、图表、代码，网络资料同样受限）｜禁止伪造或篡改数据与结果｜禁止使用他人未公开的解答。
