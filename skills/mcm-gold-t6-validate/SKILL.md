# T6 检验与稳健性

先读[阶段交接契约](../mcm-gold/references/stage-contract.md)、[对抗门禁](../mcm-gold/references/adversarial-gates.md)、[证据契约](../mcm-gold/references/evidence-contract.md)和[内置 Nature 科学图表规范](../mcm-gold/references/nature-figures.md)。本阶段的目标不是让所有结果“通过”，而是准确界定哪些结论能存活。

## 必需输入

- T5 的全部关键主张、R-id、源表、代码、输入哈希、失败样本和范围限制。
- T4 基线，T2 假设与 T3 数据缺陷。
- 摘要候选结论与主图候选；没有时先建立待检清单。

## 六类检验

1. **正确性**：检查量纲、守恒、单调、对称、边界、极端输入和退化情形；能手算的小样本必须手算。
2. **灵敏度**：优先扰动会改变摘要结论的假设和参数。范围取题面、文献或物理边界；无依据时才用 ±5/10/20%，并至少做一次多因素联合扰动。
3. **误差**：分解数据、模型、参数、数值和离散化误差，量化或给保守上界。
4. **对照**：在同一输入、预算和指标下比较主模型、基线、常识或文献方法。
5. **稳健性/不确定性**：按问题选择噪声注入、Bootstrap、分组/时序交叉验证、蒙特卡洛传播或最坏情形。
6. **复现**：从空缓存或干净环境按说明重跑，逐项核对关键数值、图和物理工件。

## 对抗审计

- 交叉实现登记数据、预处理、核心方程/几何、求解和评价各轴的共享与独立；只换插值器或绘图库不能写“完全独立”。
- 确认敏感性轴实际改变底层输入。扰动被早期替换、聚合或缓存吞掉时，该检验无效。
- 检查训练/测试泄漏、候选池覆盖、局部最优冒充全局最优、选择后推断和多重比较。
- 对每个失败写影响：数值变化、结论是否反转、需要降级的 claim、替代工件和后续动作。
- 不适用项必须写 `N/A + 原因 + 替代检查`，不得编造检验凑数。
- 逐张审主图：核心结论是否被每个面板真实支持，`n`、种子/折数、区间、检验、校正、基线和 source data 是否完整；图形语义是否把相关写成因果、局部写成全局或候选内最优写成全局最优。
- Figure contract 的 `reviewer risk` 必须有实际攻击和结论。科学结论先定，再修图；禁止通过隐藏失败情景、截断坐标或选择性配色让图“通过”。

## 产物

- `T6_VALIDATION_MATRIX.csv`：主张 x 六类检验 x R-id x 状态。
- `T6_ADVERSARIAL_REPORT.md`：攻击、失败、存活结论和降级建议。
- 灵敏度/不确定性源表、图、验证脚本和干净重跑日志。
- 更新后的 `RESULTS.md`、`CLAIM_LEDGER.csv`、`FIGURE_EVIDENCE.csv` 和 `REVIEW_PASS_ITEMS.csv`。
- `NATURE_QA.csv` 中主图统计、源数据、最终尺寸和过度主张检查记录。

## Gate

gold 档六类均有实际 R-id 或合理 N/A；所有摘要候选结论通过适用红队；验证轴确实活跃；失败结论已降级、替代或撤回；主图的统计、source data、视觉强度和 reviewer risk 已审；复现读取了实际输出。重要限制仍存但不推翻核心出口时返回 `PASS_WITH_LIMITATIONS`，并逐项传给 T7。

把确认/受限/否决主张、R-id、图表状态、复现日志和 T7 可用表述边界写入 `[HANDOFF T6]`。
